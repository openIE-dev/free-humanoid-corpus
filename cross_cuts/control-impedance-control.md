- **corpus**: private
- **creator**: MIT Salisbury Robotics Lab (Thomas Massie + Kenneth Salisbury); commercialized via SensAble Technologies / Geomagic / 3D Systems
- **disclosure**: Massie, T. H., Salisbury, J. K. 'The PHANTOM Haptic Interface: A Device for Probing Virtual Objects'. ASME Dynamic Systems and Control Division 1994.
